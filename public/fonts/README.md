# Brand-kit fonts

Latin subsets of the curated Google Fonts listed in `src/app/lib/fonts.ts`
(regular and heaviest weight), downloaded with `npm run fonts:download` so the
studio can preview them without calling Google.

Each family keeps its own license, as published on Google Fonts: the SIL Open
Font License 1.1 (https://openfontlicense.org) for most, the Apache License 2.0
for Roboto and Roboto Condensed. Details for any family:
https://fonts.google.com/specimen/<Family+Name>/license
